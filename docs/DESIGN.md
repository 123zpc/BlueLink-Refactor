# 交互与视觉设计规范（阶段 3 评审稿）

> 出品：设计组（交互）+ UI 组（视觉）｜ 版本：v0.1 ｜ 状态：待确认 ｜ 日期：2026-11-17
> 定位标准见 DECISIONS.md 第四节：成熟桌面通讯软件观感；禁用紫蓝渐变、玻璃拟态、大圆角堆叠、满屏 emoji、阴影泛滥。

## 一、信息架构

主窗口三段式（连接成功后）：

```
┌──────┬────────────┬──────────────────────────────┐
│ 导航 │ 会话/功能列表 │ 内容区                        │
│ 56px │ 260–320px   │ 聊天 / AI / 标签总览 / 设置   │
│      │             │                              │
│ 聊天 │ 搜索框      │ 顶部栏：对方信息/连接状态     │
│ AI   │ 会话列表    │ 置顶栏（有置顶时）            │
│ 标签 │ （设备会话与 │ 消息区（虚拟列表）            │
│ 收藏 │  AI 会话混排，│ 待发文件 chip 区              │
│ 设置 │  以图标区分） │ 输入区（草稿自动保存）        │
└──────┴────────────┴──────────────────────────────┘
```

- 导航栏只放一级功能图标 + 文字（聊天、AI、标签、收藏、设置），选中态用左侧 3px 指示条 + 图标变色，不用填充色块。
- 未连接时内容区为连接页（见三），导航仅"设置"可用。
- 窗口最小尺寸 900×600；小于 1100px 宽时会话列表自动收窄到 220px。

## 二、页面与状态清单（每页必须四态齐全才算设计完成）

| 页面 | 关键元素 | 必须设计的状态 |
|---|---|---|
| 连接页 | 本机连接码（大字、3+3 分组、复制按钮）、等待连接按钮、发起连接（扫描列表 + 输入码）、历史设备 | 默认 / 扫描中 / 等待中 / 连接中 / 超时失败 / 蓝牙未开启 |
| 聊天页 | 消息列表、日期分隔、置顶栏、新消息提示条、回到底部悬浮钮、输入区、待发文件 chip | 空会话 / 加载历史 / 对方输入中 / 已断开（顶部红条 + 重连）/ 发送失败 |
| AI 页 | 会话列表、流式气泡、停止/重新生成、版本切换、目录折叠区、代理角色提示条 | 未配置（引导去设置）/ 生成中 / 已停止 / 五类错误（按 REQUIREMENTS 文案）/ 代理模式 |
| 标签总览 | 标签列表（颜色点、名称、计数、搜索）、右侧消息抽屉 | 空状态引导（E1-12）/ 搜索无结果 |
| 收藏 | 与标签抽屉同构 | 空状态引导 |
| 设置页 | 分组列表：连接 / 下载 / AI / 外观 / 快捷键 / 关于 | 每项即改即存，无"保存"按钮；AI 页含测试连接与结果反馈 |

## 三、核心交互流程（文字稿，开发照此实现）

1. **连接**：打开应用 → 连接页默认展示本机码与两个主按钮 → 点"等待连接"进入等待态（可取消）→ 对方连入后 300ms 内转场到聊天页并弹出轻提示"已与 XX 连接"。发起方：点"发起连接"→ 扫描列表实时填充 → 点设备或输码确认 → 连接中显示进度 → 成功同上，失败按错误规范提示并停留在连接页。
2. **发文件**：拖入文件 → 输入区上方出现 chip → 点发送 → 气泡内进度实时更新 → 完成显示文件卡片（图标、名、大小、打开/定位文件按钮）。
3. **打标签与定位**：按 REQUIREMENTS 的 E1-01～E1-09 实现，浮层与抽屉的位置固定：标签编辑浮层锚定在消息右上方，标签消息抽屉从右侧滑出（宽 360px），定位高亮时抽屉不得遮挡目标消息（内容区自动让位）。
4. **AI 提问**：回车发送 → 用户气泡上屏 → AI 气泡以流式逐字出现，期间发送按钮变停止按钮 → 完成后出现操作行（复制、重新生成、标签、收藏）。
5. **断线**：任何页面下断线，顶部出现全局细条"连接已断开，正在重连…"，重连成功自动收起；失败变为"重连失败" + 重连按钮。不弹窗、不打断当前阅读与输入（草稿保留）。

## 四、视觉规范（UI 组定版，开发按数值还原）

- **色彩**：中性灰阶为底（浅色：背景 #F5F5F4 / 面板 #FFFFFF / 文字 #1A1A1A / 次级文字 #6B7280；深色跟随同体系）；唯一主色为克制的蓝 #2563EB，仅用于主按钮、链接、选中指示；成功绿 #16A34A、警告黄 #D97706、错误红 #DC2626。**全应用禁止渐变色**。
- **字体**：系统字体栈（Windows 微软雅黑 / macOS 苹方 / Linux 思源黑体），不打包字体；字号阶梯 12（辅助）/13（列表）/14（正文）/16（标题）/20（连接码 28）；正文行高 1.55。
- **间距与圆角**：4px 基础网格，间距只取 4/8/12/16/24；圆角：按钮与输入框 6px、气泡 8px、浮层 10px — 全应用最大圆角 10px，杜绝"大圆角玩具感"。
- **阴影**：只允许两级轻阴影用于浮层与抽屉，气泡与卡片一律不用阴影、只用 1px 边框分隔。
- **图标**：统一线性图标（1.5px 描边），不用 emoji 做功能图标；emoji 只出现在聊天内容渲染中。
- **动效**：只用于状态过渡（抽屉滑出、浮层淡入、高亮闪烁），时长 120–200ms，不做装饰性动画；定位高亮按 E1-09 的 2 次闪烁执行。
- **深色模式**：跟随系统，提供同等完整的深色色板，不允许"深色下凑合"。

## 五、还原与走查标准

- 开发还原后 UI 组按本规范走查：色值、字号、间距逐项抽查，误差超过 1px/1 级色阶即打回。
- 用户研究组按画像场景走查本稿：三类画像各走一遍连接、聊天、传文件、AI 提问、标签定位五条主路径，记录卡点，卡点未清零不进详细设计阶段。
