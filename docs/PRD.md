# 产品需求文档（PRD）

> 版本：v0.1（评审稿）｜ 状态：待确认 ｜ 日期：2026-11-17
> 确认方式：逐项确认后进入架构评审；未确认项不进入开发。

## 一、产品定位

无网环境下的桌面端点对点通讯工具：两台电脑通过蓝牙直连聊天、传文件；其中一台有网时，可为另一台提供 AI 对话代理服务。支持 Windows / macOS / Linux，观感与体验对标成熟桌面通讯软件与官方 AI 客户端。

## 二、核心功能（从原版继承的功能与思想，仅此而已）

| 编号 | 功能 | 说明 | 首版 |
|---|---|---|---|
| F1 | 设备发现与连接 | 蓝牙扫描、6 位连接码配对、连接状态与自动重连 | ✅ |
| F2 | 即时聊天 | 一对一文本聊天，低延迟，本地历史存储 | ✅ |
| F3 | 文件传输 | 任意格式与大小，拖拽发送，进度、取消、断点续传 | ✅ |
| F4 | AI 对话 | OpenAI 兼容接口，用户自填地址/密钥/模型，多轮上下文 | ✅ |
| F5 | AI 代理 | 有网机做代理，无网机经蓝牙请求 AI 并流式接收回复 | ✅ |
| F6 | 历史与设置 | 聊天/传输记录本地存储与检索；下载目录、AI、连接等设置 | ✅ |

## 三、长对话效率功能（本次新增重点）

对话一长，找内容就是最大的效率损耗。本组功能围绕"标记 — 检索 — 跳转"设计：

| 编号 | 功能 | 说明 | 首版 |
|---|---|---|---|
| E1 | **消息标签** | 对任意消息打自定义标签（一条消息可多个标签）；左侧/顶部标签栏列出全部标签及计数，点击标签列出该标签下所有消息，点击任一条**直接滚动定位到原消息并高亮闪烁** | ✅ |
| E2 | 消息收藏 | 一键星标收藏，收藏夹集中查看，同样支持点击定位原文 | ✅ |
| E3 | 会话内搜索 | 关键词搜索当前会话，结果列表 + 上一个/下一个逐条跳转，命中高亮 | ✅ |
| E4 | 会话内引用跳转 | 引用回复时，点击引用块跳回被引用的原消息 | ✅ |
| E5 | 置顶消息 | 每个会话可置顶若干条消息，置顶栏点击即达 | ✅ |
| E6 | 阅读位置记忆 | 每会话记住上次阅读位置，重进时回到原处；悬浮按钮"回到最新"与"回到未读起点" | ✅ |
| E7 | 长回复目录 | AI 长回复自动按标题生成目录侧栏，点击标题定位到该段 | ✅ |
| E8 | 日期锚点 | 按日期分隔线快速跳转到某天（日历/时间轴） | 次版 |
| E9 | 命令面板 | Ctrl+K 全局搜索：会话、标签、收藏、功能命令一处直达 | 次版 |
| E10 | 多选与导出 | 多选消息批量复制/导出为文件，长对话整理成文档 | 次版 |
| E11 | 草稿自动保存 | 每会话输入框草稿自动保存，切换会话不丢失 | ✅ |
| E12 | 全局快捷键 | Ctrl+F 会话内搜索、Ctrl+K 命令面板、Esc 关闭面板等，成体系定义 | 随 E3/E9 |

设计约束：标签、收藏、置顶等全部存本地数据库，与消息 ID 绑定；消息被删除时关联标记级联清理；跳转定位必须在虚拟滚动下可用（先定位数据，再滚动渲染，不能靠全量 DOM 查找）。

## 四、非功能需求

- **性能**：冷启动 < 1.5 秒（主流配置）；万条消息会话滚动不掉帧（虚拟列表）；文件传输内存占用恒定（与文件大小无关）。
- **稳定**：崩溃率目标 < 0.1%；传输中断可恢复；异常均有中文提示与重试路径。
- **体积**：安装包目标 ≤ 30 MB（三平台分别计量）。
- **隐私**：所有数据本地存储；AI 密钥仅存本地且加密落盘；无任何遥测上报。
- **跨平台一致性**：核心功能三平台行为一致，平台差异只允许出现在窗口/菜单等系统习惯层面。

## 五、不做（首版范围外）

群聊、多人会话、语音/视频通话、移动端、云同步、账号体系。
