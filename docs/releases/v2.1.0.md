# BlueLink v2.1.0 发布说明（蓝牙版 · 体验迭代）

发布日期：2026-11-18 ｜ 类型：客户交付版（功能迭代）

## 本版内容（按用户 2026-11-18 上午反馈逐项落地）

- **拖拽文件发送**：把文件直接拖进窗口即可发送（拖动时有全屏提示层）；未连接时拖放会明确提示先连接。原回形针选文件方式保留。
- **中间会话列表可收起**：列表头新增收起按钮，收起后聊天区变宽，左侧留一条展开条；状态会记住，重启保持。长期只连同一台设备的场景下可一直收起。
- **去掉头像**：消息、会话列表、聊天页头、AI 页头全部移除头像，靠左右对齐与气泡底色区分双方，界面更干净。
- **长消息防刷屏**：超过 500 字或 10 行的文本消息默认折叠（约 8 行高），点「展开全文」查看、点「收起」还原。
- **代码/长文本自动转文档**：在输入框粘贴或输入内容时自动识别——围栏代码块按语言、代码特征按语言家族（Rust/Python/JavaScript/Java/C/Go）生成对应后缀（.rs/.py/.js/.java/.c/.go 等），超长纯文本转 .md；发送前输入框上方有提示条，可一键改回「仍按文本发送」。
- **标签彩签**：聊天界面右上角出现本会话标签的彩签（书签式贴边），平时半透明不挡聊天，鼠标悬浮时凸显；点彩签定位到该标签标记的消息（文件消息同样可定位），连点逐条往前轮换；点彩签上的圆点可自定义标签颜色（默认 + 8 色），颜色同步到消息内的标签小签与左侧标签列表。
- **连接码说明**：连接页在设备列表下新增一行说明——点选设备后下方出现连接码输入框，填对方设备显示的 6 位码。

## 蓝牙速度说明（如实记录）

- 当前实现为稳妥优先：写特征优先用无响应写、按 200 字节分片、依赖系统蓝牙栈协商 MTU；**未做极限调优，也没有真机吞吐数据**（开发虚拟机无蓝牙硬件）。BLE 的实际速度受连接间隔与协商 MTU 影响（系统决定），量级通常为每秒几十 KB，大文件会明显慢于 Wi-Fi。真机验收时请实测一个大文件的耗时，反馈后可针对性调参（分片大小/写策略）。

## 验证状态（如实记录）

- 自动化：全工作区 17 个单元/集成测试全过，clippy 零警告，fmt 通过；GitHub CI 三平台与 Release 构建以本版发布时结果为准。
- 本机 GUI 实测（开发者模式局域网通道 + 命令行节点）：列表收起/展开、无头像聊天、长消息折叠、文档提示条与转文档发送、标签彩签与改色、连接页说明均走查（截图存档）。拖拽发送的事件通道已注册，但 Xvfb 环境无法模拟系统级拖放，未做端到端拖放实测。
- **未验证项（需要用户真机）**：两台真实设备间的蓝牙配对、聊天与文件传输（同 v2.0.1，本开发机无蓝牙硬件）；请在两台带蓝牙的设备上安装本版互连验收。
- 已知限制：安装包未签名，Windows SmartScreen / macOS Gatekeeper 首次运行会提示。
