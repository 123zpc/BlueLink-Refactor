# BlueLink v2.6.1（草稿测试包）

v2.6.0 统一真机测试的修复轮：原 17 条发现逐条处理，测试期间又陆续追加 11 条（⑱–㉛），共 28 条全部并入本轮。重点是查看器打开代码文件卡死、蓝牙重连撞上缓存旧端点、剪贴板同步影响本机复制粘贴三件实锤问题，外加 AI 会话体系归位（AI 页自带会话列表/新建/改名）、离线也能看历史、上下文按 token 预算加老内容摘要、顶栏瘦身与启动提速一组结构改造。

## 修复（按发现编号）

- **⑪ 查看器打开代码文件卡死（根因修复）**：高亮分词器遇到中文标识符/裸中文行时游标原地死循环，界面冻死。词扫描改认 Unicode 字母数字并加防呆推进；配套回归脚本喂 12 类毒行全部毫秒级返回。
- **⑯ 蓝牙缓存旧端点**：对方重启后本机连到缓存里的旧地址——无线电能通、握手必超时。现在握手超时/缓存未命中后自动清缓存、强制重扫、用新地址重试一次；双边同时发起连接时按设备 ID 字典序仲裁，一方让行接受入站，不再互撞。
- **⑬ 剪贴板同步不再影响本机**：连接时先「对账」——开同步后先登记本机当前内容为基线，不再一连接就把旧内容重写进对方；对方状态通告不再触发无条件写入；写入前先比对、本机内容没变就不写；写剪贴板遇被占用立即放弃并退让 30 秒，绝不抢占；读失败记日志（限频）。
- **⑮ 本地 API 兼容编程工具**：TRAE 等工具的消息内容是分段数组格式，此前被解析成空字符串导致上游 422 报错。现兼容数组形态（拼接文本段、跳过非文本段），temperature/max_tokens/top_p 尽量透传；网关与转发两侧补齐日志（请求/路由/上游状态/错误摘要，不记密钥）。
- **⑩⑫ AI 回复渲染 Markdown**：标题、粗体、斜体、列表、分隔线、链接、行内代码都正常渲染；代码块带头部条（语言名 + 「复制」按钮，一键复制整段原始代码）；先转义再渲染，回复里的 HTML 不会被当标签执行；流式输出中途的半截 Markdown 也能容错显示。
- **④ 提问等待反馈**：AI 页提问、聊天 @AI、问AI 三个入口，发出后立即显示等待气泡（走对方时显示「正在等待对方 AI 回复…」），首片到达原地转流式。
- **⑭ 重新生成修好**：AI 页与聊天 @AI 气泡两处「重新生成」都确实发出新请求并带等待态（聊天侧此前没有可用入口），动作记入运行日志可核对。
- **⑤ 思考模式开关**：AI 页输入区新增「思考」开关，@AI/问AI/重新生成都随请求带上并端到端转发；DeepSeek 兼容接口真正下发 thinking 参数，其他接口忽略并在回答区给出小字提示，不假装支持。
- **⑥ 流式不再抢滚动**：流式输出时只有视图在底部附近才自动跟随；上滑看历史不被打断，AI 页新增「回到最新」按钮。
- **⑦ AI 输入框对齐聊天框**：Enter 发送、Shift+Enter 换行、高度自适应；补输入法守卫——中文输入法组字时的回车不再误发（聊天框同修）。
- **③ 测试连接用表单值**：AI 配置的「测试连接」改用表单当前值直测，改完地址/模型/密钥不用先保存；密钥留空沿用已保存的。
- **② 项目地址可点击**：设置页作者信息里的项目地址可点，系统浏览器打开。
- **① 检查更新提示汉化**：取不到更新信息时的英文原文报错改为人话说明（可能尚无带更新文件的正式版发布，或网络不通），原始错误记入运行日志。
- **⑧ 文本解码更稳**：查看器解码改严格链——严格 UTF-8 → 严格 GBK → 有损兜底（按 UTF-8 损坏程度与替换符数量择优）。UTF-8 文件混个别坏字节时只坏那一两个字，不再整篇变乱码。
- **⑨ 围栏文件处理**：内容以 ```语言 开头的文件（多是从 AI 回答整段存下来的），查看器自动去掉首尾围栏行、用围栏语言高亮，不再顶部多出一行「python」。
- **⑰ 图片组气泡打磨**：卡片改中性卡面、堆叠错位与阴影柔和化、内边距收紧；「共 N 张」改小号半透明胶囊保留右上，页码指示移入图片查看器，气泡面不再挂两个徽标。
- **⑱ 图片查看器一键复制（新增）**：图片查看器工具栏加「复制图片」按钮，点击把当前显示的那张图经应用原生通道（读文件→解码→写入系统剪贴板）复制，图片组翻页时跟随当前张；成功有提示，文件已删/解码失败给人话说明。
- **⑲ AI 页置顶的消息在列表里看不到（定案修复）**：置顶本身一直正常落库、消息旁也显示「已置顶」，但置顶栏/置顶列表此前只收录设备会话、且 AI 页根本没有置顶栏——在 AI 页置顶的消息在任何列表里都找不到，重启也不会出现（数据没丢，是列表读取分叉）。现在 AI 页有自己的置顶栏与置顶列表（点开可定位回原消息），聊天页口径不变；原有置顶数据升级后自动重新列出，无需任何处理。附带加固：会话列表加载失败时保留现有列表并记日志，不再整体变空。
- **㉑ 单张图片气泡直接出预览（新增）**：单张发送的图片不再是光秃秃的文件卡——气泡里直接渲染预览缩略图（尺寸克制、不变形），点击进图片查看器（与图片组同一查看器）；接收的图片在传输完成时自动补上预览；非图片文件保持文件卡不变。
- **⑳ 发文件后等校验不再久等**：分段计时定案——字节传完后的等待主要耗在接收端每片落盘的同步写与收尾三笔分开提交的数据库写入上（增量哈希本身不背锅）。现改为接收缓冲句柄常驻、每 32 片才落一次续传进度、收尾三笔回写合并成一个事务。局域网实测：100KB 文件等校验从约 340ms 降到约 87ms；30MB 文件从约 2.2 秒降到约 0.4 秒，整体传输总耗时也明显缩短。
- **㉒ 「问AI」改草稿式**：点「问AI」不再立刻把消息原文发出去——先切到 AI 页把该消息挂成输入框上方的引用条（可取消），你补充自己的问题后再发送，引用内容与问题一起组装；什么都不输直接发送则按旧行为把原文当问题。落点维持原裁定：仍进「AI 助手」会话。
- **㉓ 上下文按 token 预算 + 老内容摘要**：组装上下文从「最近 20 条」改为按估算 token 预算（约 24K，中文约 1 字 1 token、英文约 4 字符 1 token）从新往旧装；被预算挤掉的老对话不直接丢——首次溢出时用同模型摘成一段 300 字以内的纪要存下，之后每次发送把纪要作为注记放在历史最前面，早期聊过的话题问起来还能答出大意；摘要增量更新不重复烧钱，生成失败自动退化为纯截断、不挡发送。本机与对方转发共用同一套组装。
- **㉔ 收藏跳转落点修正**：从收藏点一条 AI 消息跳回去经常落偏——根因是跳转与分页加载并发重渲染同一容器把落点冲掉、且滚动在布局落定前执行。现在跳转期间独占渲染、待布局落定后再滚动定位并在短窗口内校正一次，长会话深处与最近一条都落点准确。
- **㉕ AI 会话体系归位**：AI 页自带会话列表（顶部会话条），可新建会话、双击改名并持久化；AI 页发送跟随当前打开的会话，各会话互不串话；聊天页会话列表只列对端会话、不再混入 AI 会话。「问AI」落点不变（仍进「AI 助手」）；原有「AI 助手」历史一条不少，既有 AI 会话原样出现在新列表里。⑲ 的置顶问题在此框架内一并回归通过。
- **㉖ 置顶消息右键取消（带二次确认）**：置顶栏/置顶列表条目右键弹出菜单含「取消置顶」，点击后先弹确认框，确认才真正取消（取消/关弹窗不做任何变更）；消息气泡自身的右键菜单同步补齐收藏/置顶。左键跳转行为不变，取消后重启仍保持。
- **㉗ 启动窗口居中**：根因是窗口既没设居中、也没有位置持久化，全靠系统默认放置（总是靠下）。现改为每次进程启动按主显示器工作区实测居中（尺寸按配置×缩放比现算，禁止写死坐标），工作区小于窗口时钳回左上角保标题栏可见；只在启动时居中——托盘恢复仍回到隐藏前的位置，不受影响。
- **㉘ 启动不再白屏**：窗口底色改成应用底色并内置启动外壳（品牌+应用名+加载指示），窗口一出现就有内容、外壳不设最短停留、主界面就绪立刻切走；BLE 中心端/服务端初始化改并行。实测（本机虚拟屏、调试构建）：进程拉起→窗口可见约 1.2 秒且第一帧即应用底色（改前约 0.7 秒但为纯白屏）、→主界面可交互约 3.1 秒（含测试脚本固定等待，实际更低）。
- **㉙ 本地 API 显示可用模型**：设置页本地 API 区块新增「可用模型」一行，三种口径用人话区分：本机已配 AI 显示真实模型名并标注（本机）；本机未配但已连接对方显示 bluelink-proxy 并注明（经对方设备 AI 转发）；都没有则明确显示「暂无可用模型」及原因。开关切换、连接状态变化、AI 配置保存后都会自动刷新。
- **㉚ 顶栏瘦身**：聊天页与 AI 页顶栏统一为约 50px 单行紧凑栏，与消息区左右对齐、控件统一高度与间距节奏、字阶分明（标题半粗、状态弱化小字）；聊天页连接状态降为名字旁的小圆点+小字，导出改图标按钮、断开改无边框危险色文字按钮；AI 页来源说明并入标题行弱化显示（可截断、悬停看全），本地 API 改带状态点的紧凑胶囊。功能入口一个不少，深色模式同步打磨，改前/改后对照截图见 qa/ 目录 v261-header-* 与 v261-group-*。
- **㉛ 没连接也能看历史**：根因是聊天页的显示被绑死在连接状态上——未连接时整个聊天页被连接页顶替，断开还会被踢出正在看的会话。现在连接页与聊天页在左侧导航平级、随时互切，浏览历史零拦截；未连接打开会话时输入框位置换成提示带「当前未连接，只能查看记录」加「去连接」按钮，顶栏如实显示连接状态（在会话 A 里连着 B 时会写明当前连接对象）；连接成功后一律落到实际连上的那个对端的会话；导航聊天图标带连接状态小圆点（灰/绿）；切走再切回保持原来打开的会话与浏览位置。

- ⑯ 的缓存重试与双边仲裁、剪贴板新规矩都需要在真机双机环境复测（本机无蓝牙硬件，只完成了逻辑与单测验证）。
