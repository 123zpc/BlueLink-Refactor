# BlueLink v2.3.0（测试版，未正式发布）

> 这是供真机确认的**测试版**，不是正式版。经典蓝牙为本版唯一新增内容，上层功能与 v2.2.2 完全一致。

## 本版变化

- **经典蓝牙（RFCOMM）成为默认传输**：照老版本 BlueLink 已真机验证的配方实现——Winsock AF_BTH + `WSASetService` 注册标准 SPP 服务、RFCOMM 端口 7、经典 Inquiry 搜索（无 UUID 过滤，已配对/记住的设备也会列出）、按蓝牙地址经 SDP 解析通道直连。应用启动时经典蓝牙服务端与原 BLE 服务端并行开启。
- **开发者模式入口变更**：设置页连续点击版本号三次开关开发者模式；传输方式选择（经典蓝牙 / BLE）收进开发者模式，普通模式连接页不出现传输选择。局域网仍仅在开发者模式下可用。
- **上层功能不变**：聊天、文件传输、彩签分类、AI 与 AI 代理网关、连接码握手协议均与 v2.2.2 相同，一行未改。

## 验证状态（务必先看）

- 已验证：本机编译通过、单元测试 23 个全过、Clippy 零警告、Windows 目标交叉编译检查通过。
- **未经真机验证**：经典蓝牙的扫描、配对、连接、实际传输速度，本开发环境无蓝牙硬件，**全部待实机测试后才能确认**。本测试版即为此而出。
- 真机测试重点：①两台 Windows 能否互相扫描到；②首次连接的系统配对流程是否顺畅、配对后能否自动直连；③10 兆文件实测耗时；④连接页「上次连接」一键重连（经典蓝牙路径）。

## 已知事项

- Linux / macOS 的经典蓝牙尚未实现，这两端仍用 BLE。
- 设备名目前只能查看不能改名（设置页只读），沿袭 v2.2.2 的记录，待后续裁定。
- 安装包未签名，Windows 可能弹出 SmartScreen 提示。
