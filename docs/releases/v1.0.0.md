# v1.0.0 客户交付版（首个发到客户的版本）

> 循环第 3 圈 ｜ 日期：2026-11-18 凌晨 ｜ 性质：**交付客户版** — 必须可用、基础功能完善（发起人定版标准）

## 甲方需求（客户代表）

- 桌面应用本体：三平台（Windows/macOS/Linux），界面按 DESIGN.md 定版规范，不许玩具感。
- 基础功能完善：连接（连接码）、聊天、文件传输（进度/续传）、标签、收藏、置顶、搜索、草稿、AI 对话（直连 + 经对方代理）、设置。
- 交付标准：能装、能开、能连、能聊、能传，关键路径有自动化测试与实机截图为据。

## 乙方交付

- app/（Tauri 2）：命令层实现详细设计第三章的全部 IPC；节点事件实时转发前端。
- ui/（原生 HTML/CSS/JS，无框架）：三段式布局、连接页、聊天页、AI 页、标签总览 + 消息抽屉、收藏、会话内/全局搜索、设置页；视觉 token 与 DESIGN.md 一一对应（无渐变、圆角 ≤10px、唯一主色 #2563EB、系统字体）。
- 定位链路按架构定版只实现一次（locateMessage），标签/收藏/搜索/置顶共用。
- 存储层补 delete_message（AI 重新生成替换旧回复）；服务层补 ai_regenerate。

## 测试报告（测试组）

- 全量自动化测试 15 个全过（单元 + 端到端：聊天/回执、文件哈希一致、断点续传、AI 代理）。
- Linux 桌面应用构建成功（debug 与 release 两种配置）；虚拟显示下启动冒烟通过：应用稳定运行、数据目录与数据库正常生成。
- GUI 截图验收（UI 组走查）：连接页与设计规范一致 — 布局、色值、圆角、字号均符合 DESIGN.md 数值。
- CLI 双节点实测：连接码握手、双向聊天、2MB 文件传输 MD5 一致。

## 客户验收（客户代表 + 用户研究组）

- 验收结论：**通过，作为首个客户版本发布**。基础功能齐备且有测试与截图证据，达到"可用"标准。
- 验收保留项（不拦发布、必须如实写入已知问题）：
  1. 当前连接通道为局域网 TCP；蓝牙通道（BLE/RFCOMM 平台后端）未接入 — 与原版"纯蓝牙"定位有差距，列为后续循环的最高优先级需求。
  2. GUI 全流程键鼠自动化在虚拟显示环境下注入不可靠，未能取证；已用服务层端到端测试 + CLI 实测 + GUI 渲染截图三段证据替代，真机点按验证列入下一轮 UAT。
  3. Windows/macOS 安装包未在本机产出，由 CI 三平台构建验证编译，安装包分发列入下一循环。

## 已知问题（发布说明同步）

- 仅支持局域网 TCP 连接（需同网段或手动路由），蓝牙即将推出。
- AI 重新生成会替换上一条回复（多版本切换在后续版本提供）。
- 文件传输进度条按最近一个文件气泡展示，并发多文件时进度归属可能不精确。

## 复盘回流（进入下一圈需求池）

- [最高] 蓝牙双通道后端（BLE 发现/聊天 + 平台高速通道传文件）。
- AI 回复多版本切换；Ctrl+K 命令面板；日期锚点；多选导出（PRD 次版清单）。
- 传输并发进度归属精确化；Windows/macOS 安装包与签名。
