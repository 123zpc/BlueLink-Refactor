# BlueLink 1.0.0

BlueLink 1.0.0 是 BlueLink 的首个正式版本。BlueLink 是一款**离线蓝牙聊天与文件传输**应用：两台电脑之间不需要网络、不需要服务器、不需要注册账号，配对连接后即可互发消息与文件，特别适合内网、隔离网络等不方便联网的环境。

本应用是 BlueLink 的 Rust 重构优化版，使用 Rust + Tauri 2 重新实现，界面与交互全面现代化，传输层针对速度与稳定性做了重点打磨。

## 核心功能

- **离线蓝牙聊天**：经典蓝牙直连，首次连接在系统里确认配对一次，之后自动直连；支持文字、图片、文件、引用回复。
- **高速文件传输**：流式压缩（zstd）、大缓冲批量发送、断点续传与 SHA-256 完整性校验；接收文件按日期自动归档。
- **三种传输方式**：经典蓝牙（默认）、BLE、SimpleBLE，后两者在「开发者模式」中开启（设置页连点版本号三下）。
- **AI 助手**：可配置任意 OpenAI 兼容接口；聊天里可以把任意消息「问 AI」，也可以在聊天框用 `@AI` 向对方设备的 AI 提问（问答只保存在本机，不经过聊天通道发送）。密钥只保存在持有方电脑上，永不通过蓝牙传输。
- **本地 API**：在本机开放 OpenAI 兼容接口（`http://127.0.0.1:8321/v1`），供本机其他软件调用已配置的 AI 或已连接对方设备的 AI。
- **彩签分类**：9 种颜色即 9 个分类，为消息选色即归类，每种颜色可自定义名称，改名全类同步。
- **内置查看器**：文本/代码文件在应用内只读打开，支持语法高亮、查找、格式化整理（JSON / JavaScript / Python / SQL / MagicAPI / C 风格语言）与改名（改后缀即按新类型重新高亮）。
- **剪贴板同步**：可与已连接设备双向同步剪贴板（文字与图片，双方都开启才生效，单份上限 2MB）。
- **收藏与置顶**：消息可收藏、置顶，收藏页与彩签页可按分类浏览、搜索定位。
- **检查更新**：设置页可手动检查更新，只提供正式版。

## 稳定性（本版重点）

- **手动断开不再被自动重连**：任一方主动断开时先发送告别信号，对方识别后不会再自动连回；只有意外中断才会按退避策略自动重连回原会话。
- **传输乱序重组**：蓝牙切片乱序到达时按序号入座重组，不再把乱序误判为丢失；多图连发、快速连发多个文件时每个文件的进度独立记账，全部正确落定。
- **剪贴板防回声**：同步写入的内容带登记标记，不会被再次回传或重复发送。
- **AI 回复定位**：等待与流式输出的气泡始终紧贴所回答的问题，回复再长也不会错位。

## 安装

- Windows：下载 `.msi` 或 `.exe` 安装包运行安装。
- macOS：下载 `.dmg`，拖入「应用程序」。
- Linux：提供 `.deb` / `.rpm` / AppImage，按发行版习惯安装。

安装包未做代码签名，Windows SmartScreen 或 macOS Gatekeeper 可能给出提示，选择「仍要运行 / 允许打开」即可。

## 使用要点

1. 两台电脑都打开 BlueLink，在一台上点选另一台设备，输入对方屏幕上显示的 6 位连接码即可连接。
2. 连接码由设备身份生成、固定不变，同一台设备每次都是同一个码。
3. AI 功能需要在设置页填入接口地址、密钥与模型名；也可以不配自己的 AI、借用对方已开启「AI 转发」的设备。
4. 文件传输速度受蓝牙硬件上限约束：经典蓝牙 EDR 约 2 Mbps，10 MB 不可压缩文件约需 1 分钟，这是物理上限。

## 已知限制

- 经典蓝牙目前以 Windows 为先行平台；macOS 上建议使用 BLE / SimpleBLE（开发者模式）。
- 本地 API 只监听本机回环地址，不对外提供服务。
- 剪贴板图片同步在个别系统上可能有格式差异，文字同步不受影响。
