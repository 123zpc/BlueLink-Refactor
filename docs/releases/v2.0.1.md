# BlueLink v2.0.1 发布说明（蓝牙版，取代未发布的 v2.0.0）

发布日期：2026-11-18 ｜ 类型：客户交付版（大版本 + 发布前缺陷修复）

## 本版内容

与 v2.0.0 计划内容一致（详见 docs/releases/v2.0.0.md 的定版事项、蓝牙实现与界面三轮迭代记录）：

- 产品通道定版为蓝牙（BLE GATT：广播/扫描/点选连接/连接码校验，聊天与文件走蓝牙字节流）；局域网仅保留在「设置 → 开发者模式」（默认关闭，命令层门禁）。
- 界面按大厂桌面通讯规范重做三轮：SVG 图标系统、头像与消息分组、文件卡片、深色模式三档、蓝牙扫描配对连接页。

## 发布前缺陷修复（v2.0.0 → v2.0.1）

- **缺陷**：应用缺少 Tauri 2 权限配置（capabilities 文件），前端 `listen` 订阅被系统拒绝，实时事件（连接状态、新消息、回执、传输进度）全部无法到达界面。表现为：后端连接与消息收发正常（数据已落库），但界面停留在连接页、不自动进入聊天、新消息不刷新。自 v1.0.0 起即存在，因当时 GUI 全流程自动化未覆盖而漏检，本次在 v2.0.0 的安装包 GUI 实测中发现。
- **修复**：新增 `app/capabilities/default.json`，为主窗口授予 `core:default`（含事件订阅）与 `dialog:default`（文件对话框）；前端启动流程对事件订阅失败做隔离处理，避免单点失败拖垮其余初始化。
- **复验**：修复后重新打包安装，在本机以开发者模式局域网通道与命令行节点完成全流程 GUI 实测：连接建立后界面自动切换到聊天页、对端消息实时上屏、会话列表同步出现（截图存档）。蓝牙通道与局域网通道共用同一事件路径，本修复对蓝牙同样生效。

## 验证状态（如实记录）

- 自动化：全工作区 17 个单元/集成测试全过，clippy 零警告；GitHub CI 三平台（Ubuntu/Windows/macOS）全绿；安装包由 Release 工作流在三平台构建。
- 本机：Linux .deb 构建、安装、启动、各页面截图走查通过（连接页/设置页/开发者模式/聊天页）。
- **未验证项（需要用户真机）**：两台真实设备间的蓝牙配对、聊天与文件传输。本开发机（虚拟机）无蓝牙硬件，无法完成真机链路验证；请在两台带蓝牙的设备（Windows/Linux/macOS）上安装本版后互连验收。
- 已知限制：BLE 带宽有限，大文件传输速度低于局域网/Wi-Fi 通道（功能可用，速度受蓝牙物理层限制）；安装包未签名，Windows SmartScreen / macOS Gatekeeper 首次运行会提示。
