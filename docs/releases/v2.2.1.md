# BlueLink v2.2.1 发布说明（v2.2.0 修正版）

发布日期：2026-11-18 ｜ 类型：客户交付版（缺陷修正）

本版功能与 v2.2.0 完全一致（见 v2.2.0 发布说明），只修三处交付缺陷，**取代 v2.2.0**：

- **安装包版本号修正**：v2.2.0 的安装包文件名与包内版本号误写为 2.1.0（打包配置 `app/tauri.conf.json` 的版本号未随主版本同步）。本版起两个版本出处统一为 2.2.1；设置页「关于」显示的版本号改为运行时读取应用包版本，不再在页面里写死，避免再次脱节。
- **Windows / macOS 的 CI 修复**：v2.2.0 在这两个平台的 Clippy 检查（警告即错误）未通过——「打开文件位置」的 Windows/macOS 分支各有一处多余的 `return`（`needless_return`），Linux 分支无此写法故未暴露。已改为与 Linux 分支一致的表达式写法。
- v2.2.0 发布页正文为空的问题：本版发布页附完整说明。

## 验证状态

- 本机：全工作区 Clippy 零警告（Linux）；自动化测试 20 个全过（应用壳所在 crate 因本机虚拟机缺 WebKit 运行库无法本地链接，其编译由三平台 CI 覆盖）。
- 三平台 CI 与 Release 构建结果见 GitHub，本说明定稿时以 CI 全绿为准入条件。
- 仍未验证（与 v2.2.0 相同）：真机双设备蓝牙配对/聊天/传文件（需用户两台真实设备）、粘贴图片完整发送链、安装包未签名。
