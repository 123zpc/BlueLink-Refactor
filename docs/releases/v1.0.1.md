# BlueLink 1.0.1

BlueLink 1.0.1 是 1.0.0 正式版之后的第一版维护更新，内容来自真实使用中的反馈：一项新功能（AI 文本附件）、一处工具栏合并，其余为显示与粘贴方面的修复打磨。原有功能与使用方式不变。

## 新增：AI 文本附件

- 在 AI 页提问时可以附带文本文件：点输入框旁的回形针选择文件，或把文件直接拖进 AI 页，待发文件会以小文件片排在输入框上方，可逐个移除。
- 发送后，文件内容会随问题一起交给 AI 阅读；对话里这条消息会带着文件片（文件名和大小），点开就能查看文件内容，重启应用后也还在。
- 只支持文本类文件（文档、代码、表格文本、日志等）；图片等非文本文件会被明确提示不支持。单个文件和全部附件合计都有 512 KB 的上限，超限会提示并拒绝，不会悄悄截断内容。
- 本机 AI 和「用对方设备的 AI」两种方式都支持附件。

## 修复与打磨

- **截图粘贴**：用系统截图后直接在聊天输入框粘贴，现在能把截图作为图片附件发出去；此前会误报「未能读取粘贴的文件」而丢掉截图。
- **系统通知**：收到图片组时，通知正文不再显示一串看不懂的原始数据，改为「图片组 · 共 N 张」这样的人话摘要；文件、图片等其他消息类型的通知摘要也一并对齐。
- **查看器工具栏**：给文件改名时，顶栏的输入框和按钮不再互相挤压、文字不再被挤成竖排；改名时其余按钮会暂时让位，改完自动恢复。
- **格式化合并**：查看器里的「格式化」按钮和「格式化处理」下拉合并为一个「格式化」菜单，按语言格式化和原有的各项处理（JSON 美化/压缩、Base64、URL 编解码、时间戳转换等）都在菜单里，点一项即执行。
- **图片组外观**：叠放的卡片与上方时间行之间的距离略微加大，卡片边缘不再被气泡边缘裁掉一截。
- **图片切换箭头**：图片组和图片查看器里左右切换圆钮中的箭头改到正中心，此前箭头偏在一边。
- **AI 会话片边缘**：选中的「AI 助手」会话片边缘不再透出一圈方形蓝框。
- **「思考」开关**：AI 输入框旁的「思考」片去掉了里面的小方框，改为整片颜色表示开关——蓝色是开，灰色是关。

## 安装与升级

- 已安装 1.0.0 的用户：在设置页点「检查更新」即可升级到 1.0.1；也可以下载本页安装包覆盖安装，会话与设置都会保留。
- Windows：下载 `.msi` 或 `.exe` 安装包运行安装。
- macOS：下载 `.dmg`，拖入「应用程序」。
- Linux：提供 `.deb` / `.AppImage`。
