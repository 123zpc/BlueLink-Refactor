# BlueLink 1.0.4

## 新增
- Win+V 可触发剪贴板手动同步（与原有快捷键并存，系统剪贴板历史面板照常弹出）
- 批量发送多个文件时，未轮到的文件会先显示排队状态

## 改进
- 文件传输进度改为气泡外侧的圆环显示，传输全程气泡大小不再变化，完成时有对号确认动效
- 发送进度按实际已发送字节计算，与接收端进度对齐，不再虚高
- 剪贴板被其他程序占用时，手动同步会明确提示本次未读到新内容，不再默默发送旧内容

## 修复
- 从托盘恢复窗口后不触发焦点恢复与消息贴底的问题
- 窗口恢复后焦点恢复只执行不验证、偶发仍落不到输入框的问题
- 日志时间戳与本地时间差 8 小时的问题（改为 UTC+8）
