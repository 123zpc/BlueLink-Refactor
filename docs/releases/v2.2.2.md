# BlueLink v2.2.2 发布说明

发布日期：2026-11-18 ｜ 类型：客户交付版（v2.2.1 真机反馈修正 + 功能增补）

本版针对 v2.2.1 真机验收提出的问题逐项修正，并按客户后续要求增补了托盘、日志、问AI 等功能。全部改动均通过仓库内 `docs/QA_ACCEPTANCE.md` 逐项点检（实际运行逐页逐按钮点测）后，经客户确认发版。

## 界面与结构修正

- **会话列表只属于聊天页**：彩签、收藏改为独立页面，设置页不再挂着空的会话列表列；会话列表收起时整列消失、不留残条；**每次启动都以收起状态进入**（本次运行内可展开，重启回到收起）。
- **设置页布局**：滚动条回到窗口右缘（滚动层整宽、内容层居中），不再悬在页面中间。
- **输入框**：改为悬浮卡片（圆角、软阴影、聚焦强调环）；高度随内容自适应（上限约 7 行后框内滚动，细滚动条）；发送键为圆形上箭头。
- **标题栏跟随主题**：切换深/浅色时原生窗口标题栏同步，不再出现白色标题栏配深色界面。
- **弹窗统一**：全部原生 alert 改为应用内轻提示（toast）；右键不再弹出浏览器默认菜单（输入框除外）。

## 标志（Logo）

- 客户从 5 款方案中选定 **B 斜扣链节**：两个 45° 链节环扣，左节 = 本机、右节 = 链接的机器，交叠处右节在上；未连接时右节变淡，连接后变实；发送/接收/对方输入/文件传输时对应侧有呼吸特效。左上角与连接页标志为蓝色线形（无蓝底），应用图标为蓝底圆角方 + 白色双链节，全套图标已重做。

## 系统托盘与运行日志

- **关闭窗口缩到系统托盘**（托盘菜单：打开 BlueLink / 退出；点托盘图标恢复窗口）。托盘库不可用的环境有防崩守卫，不会拦截关闭。
- **运行日志**：按天落盘到数据目录 `logs/bluelink-YYYY-MM-DD.log`，启动、连接、文件、蓝牙与本地 API 的关键事件与失败原因都记录；设置页有「打开日志目录」。

## 连接

- **记住上次连接的设备**：连接成功后自动记住（名称、方式、地址/设备 ID、连接码）；连接页出现「上次连接」一行，点「连接」直接重连——局域网直连，蓝牙自动后台扫描找到即连，不用再开扫描列表、不用再输连接码；可清除。蓝牙一键重连路径已实现，真机待验证（见下）。
- **蓝牙扫描加固**：去掉系统级服务 UUID 过滤、扫描轮询容错、广播失败原因进界面与日志。**v2.2.1「真机扫描不到」的根因仍未确认**，本版做了能做的加固；复测时请回传：另一台设备的系统与版本、两台设备连接页顶部蓝牙状态行原文、当日日志文件（设置页可打开日志目录）。另已立项对照老版本（经典蓝牙 RFCOMM）的连接方式做根因研究。
- 连接页补充连接码位置说明；信号强度改为格数图标（按 RSSI 填格，悬停显示 dBm）。

## 下载目录与存储

- **下载目录可修改**：设置页可更改接收文件目录（立即生效并持久化），可恢复默认。
- 设置页每次进入都刷新身份与目录信息，不再显示过期值。

## 彩签（颜色即分类）细节定版

- 悬停彩签的列表：条目主行显示打签时的**备注**（无备注显示正文摘要），副行 = 时间 + 正文节选；备注与副行都**单行不换行、过长省略号**，列表宽度固定 300px；鼠标移到条目上提示完整备注。
- 气泡下方小片**只显示分类名**，备注不常驻；鼠标悬浮小片时以提示显示完整备注。小片悬浮不做染色等视觉变化。
- 定位高亮改为只给气泡加一圈分类色光环（彩签路径用分类色，引用/搜索/收藏/置顶用蓝色），不再整行刷色。
- 悬停彩签列表过高时内部滚动（最高 46vh）。

## 聊天体验

- **分页懒加载**：首屏最近 100 条，向上滚动自动补页（每页 100 条），补页不跳阅读位置；消息再多打开也不卡。
- **回到底部按钮**：离底部较远时右下角出现，点击平滑回底。
- **消息搜索改为子串匹配**：中文任意片段可搜（此前整词匹配搜不到子串）。
- 本机消息的「已送达 + 时间」始终贴气泡右缘，悬停出现操作按钮时不再跳动。
- 置顶全链已补验：置顶条显示、点击定位、取消置顶。

## 问AI（本版新增）

- **默认AI 可选来源**：AI 页右上角「默认AI」下拉——自动 / 本机AI / 对方设备AI。A、B 两台都配了 AI 时，A 连上 B 后可以把默认AI 设成 B 的 AI；副标题如实显示当前来源。
- **消息「问AI」**：任意聊天消息的悬停操作新增「问AI」，把该条消息带出处作为上下文发给默认AI，自动跳到 AI 页出回答，可继续追问。
- **聊天框 @AI**：输入 @ 弹出全部 AI 选项（本机AI、对方设备名的AI、默认AI），选定后这条消息不发给对方，而是问所选 AI；问题与回答都落在当前聊天里，回答带「AI 回答」标记（仅本机保存，不会发到对方）。

## 验证状态

- 本机实测（点检表 26 条，见 `docs/QA_ACCEPTANCE.md`）：上述界面、托盘（含关窗隐藏后连接保持、消息入库）、日志、下载目录改动、彩签显示口径、分页、回到底部、置顶、默认AI 三种来源、问AI、@AI 两路（本机直连 / 经对端转发，且确认问题不作为聊天消息发出）均逐项点过并录像留档。
- 自动化：全工作区 Clippy 零警告；单测 20/20。
- **仍未验证**：真机蓝牙双机全项（开发虚拟机无蓝牙硬件），含 v2.2.1 扫描不到的根因与蓝牙一键重连；托盘在真实桌面（有托盘宿主）上的点击恢复；Windows/macOS 实机（由三平台 CI 覆盖构建）；安装包未签名。
- 设备名目前只能查看不能改名（设置页只读），已记录待客户裁定。
