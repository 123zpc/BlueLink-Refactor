# BlueLink v2.6.4（草稿测试包）

单项补丁，只落地一件事：**入口模型定版**（用户 2026-11-22 亲自复述并确认）。本轮只有前端导航逻辑变更，零 Rust 改动，与 v2.6.2/v2.6.3 协议完全互通。

## 定版模型与实现

1. **未连接时点左栏「聊天」→ 一律落连接页**（不分有无会话）。不再出现「进到聊天页但没选会话」的空态落点（旧版顶栏回退显示「暂无会话」的那种页面，任何导航路径都到不了了）。
2. **进会话详情的手动路径唯一**：展开会话列表 → 点某个具体会话 → 进该会话详情。未连接时即离线历史形态（顶栏如实标未连接、底部提示带 +「去连接」），此形态不变。
3. **会话列表在连接页也能展开**：会话列表与骑分界线的圆形悬浮展开按钮由「仅聊天页可用」提升为应用级（聊天页与连接页都可用）。既有规矩不变：每次启动默认收起、切页保持、永不自动弹开；聊天页原有行为无回归。
4. **已连接时点「聊天」→ 当前连接对端的会话**。
5. **切回恢复优先**：已经打开着某个会话详情时，切去别的页再点「聊天」切回 → 恢复刚才那个会话详情。判定顺序：先恢复已打开的详情；没有才按连接状态分流（已连接→对端会话、未连接→连接页）。
6. 冷启动落连接页、连接成功自动落对端会话、身处连接页左栏无高亮、左栏无「连接」项（v2.6.3 已落地，本轮无回归）。

左栏「聊天」、命令面板（Ctrl+K）的「打开：聊天」、连接页已连接卡上的「进入聊天」三个同义入口统一走同一条分流（goChat），口径一致。

## 验收对照

- 未连接（且已有会话）点「聊天」→ 落连接页：rig 实证（qa/v264-01）。
- 连接页展开会话列表、点「节点H」进离线详情（历史可见、底部提示带在场）：rig 实证（qa/v264-05、qa/v264-02）。
- 详情切去 AI 页再点「聊天」→ 恢复原详情（未被未连接分流冲掉）：rig 实证（qa/v264-03）。
- 已连接时从 AI 页点「聊天」→ 当前连接对端的会话：rig 实证（qa/v264-04）。
