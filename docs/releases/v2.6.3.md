# BlueLink v2.6.3（草稿测试包）

单点补丁，只修一处：**左侧功能区撤掉「连接」项**（用户验 v2.6.2 时裁定）。

## 变更内容

- 连接是一个独立功能模块（整页），不是左栏里的一个页签。左栏导航现只保留：聊天、AI、彩签、收藏、设置（底部）。
- 连接页本体与进入路径不变，一条没断：
  - 冷启动默认落连接页（v2.6.2 #2 定版）；
  - 未连接看历史时，底部提示带的「去连接」按钮进连接页；
  - 聊天页顶栏的连接状态胶囊点击也可进连接页；
  - 连接成功后仍按既定落点规则，落到实际连上对端的会话。
- 身处连接页时左栏没有任何一项高亮（连接页不是左栏目的地）；聊天图标上的连接状态小圆点保留不变。
- 已连接时的断开入口沿用聊天/会话侧既有控件，未新增入口。

除此之外无任何功能、界面或协议变更；与 v2.6.2 完全互通。
