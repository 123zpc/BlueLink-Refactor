# BlueLink v2.4.1（测试版，未正式发布）

本版是 v2.4.0 的修复轮，针对真机回传日志与实测反馈修七件事：**SCANPROBE 的 WinRT-AEP 探针修好**、**会话列表不再自己弹开（开关改悬浮按钮）**、顺查了日志里重复出现的「节点启动」，另加**「默认AI」下拉样式统一**、**彩签页补上分类改名入口**与**分类详情抽屉不再漏到其他页面**。仍为**测试版**：经典蓝牙的配对、连接、传输速度等运行时行为待真机确认后再走正式发版。

## 1. SCANPROBE 探针修复（请复跑一次经典扫描并回传日志）

v2.4.0 真机日志显示：每次扫描探针都在报「SCANPROBE WinRT-AEP 枚举失败：Property key syntax error … (0x8002802B)」，AEP 一节一条数据都没拿到。

- **根因**：申请的 13 个属性键里混了一个不存在的键 `System.Devices.Aep.ModelNumber`（逐项核对微软官方《Device information properties》的 AssociationEndpoint 属性表：型号只有 ModelId 与 ModelName，没有 ModelNumber）。一个坏键就让整组属性申请被系统拒绝，枚举根本没跑起来。
- **修法**：①剔除坏键，改用官方的 ModelId + ModelName，键表共 14 个；②改成防御式申请——先用试建 DeviceWatcher 的办法逐个验键，坏键只在日志里记一行「SCANPROBE AEP 属性键无效：<键>」并跳过，绝不再连累整组；③枚举本身带降级链（完整键集 → 核心键组 → 空属性集），保证 AEP 一节每次必有产出。经典 Inquiry 与 BLE 两路探针没动，分段格式（行首 SCANPROBE、逐设备开始/结束）不变。
- **请协助复测**：装好本包 → 连接页点一次「扫描」（经典蓝牙模式），等设备列表出齐 → 设置 → 存储 → 运行日志 →「打开目录」→ 把当天的 `bluelink-YYYY-MM-DD.log` 发回。日志里搜 **SCANPROBE**：这次应能看到「WinRT-AEP 属性枚举」一节逐台设备逐项列出（重点看 SignalStrength 到底有没有值），据此定案经典设备行要不要显示信号格。

## 2. 会话列表不再自动弹开

- **根因**：点左侧导航切到「聊天」时，旧代码里有一段「列表若是收起的就强制展开」的逻辑，所以每次切换菜单回到聊天页（甚至在聊天页再点一次「聊天」），列表都会自己弹出来，与「每次启动默认收起」的定版口径冲突。
- **修法**：删掉该强制展开逻辑——页面切换永不改变列表状态。展开/收起入口按新定版收敛为一个：**骑在左侧导航与内容区分界线上的圆形悬浮按钮**（垂直居中、不占布局宽度、带轻微阴影），收起时贴导航右缘、展开时跟到列表右缘，图标随状态翻转（» 展开 / « 收起），仅在聊天页出现；此前的页头展开按钮与列表头收起按钮已删除。你手动展开后切走再切回，保持展开；收起后怎么切都不再弹开。启动默认收起不变。
- 本地已完整复现旧 bug 并复验修复（收起态多轮切页不弹开、展开态多轮切页保持、收起后重演原触发序列仍收起），自测录像与截图存档备查。

## 3. 「默认AI」下拉与「本地 API」按钮样式统一

AI 页右上角的「默认AI」来源选择原来是系统原生下拉控件（灰色立体边框、自带箭头），与旁边扁平的「本地 API」按钮完全两个风格。本版把它改成与应用按钮同款：同高、同圆角、同边框与底色、用界面令牌色、自绘小箭头，浅色/深色主题都成立，与「本地 API」按钮排成一组。功能不变：三个选项（自动/本机AI/对方设备AI）与保存行为都没动。

## 4. 彩签页补上分类改名入口

- **问题根因**：改名功能原本只藏在聊天页的右键里（右键消息下的彩签小片、右键聊天页右上角的彩签条），彩签页本身没有任何入口；而且改名弹层在页面结构上挂在聊天页内部，从彩签页就算调起也会被藏住看不见。
- **本版修法**：①彩签页点开任意分类，详情标题「分类：X（n）」旁新增「重命名」按钮，点开变内联输入框（回车或点 ✓ 保存、Esc 或点 ✕ 取消；空名会提示且不保存；最长 16 字）；②彩签页分类行右键也能打开改名层（改名层已移到顶层，哪个页面调起都可见）；③改名后彩签页列表与详情标题、聊天页消息下小片、聊天页彩签悬停列表三处同步显示新名。消息归属按颜色关联，改名不影响已归类的消息。

## 5. 分类详情抽屉不再漏到其他页面

- **顺查发现（属实，已修）**：彩签页右侧的分类详情抽屉（「分类：X（n）」）开着不关时，切到 AI、设置等任何页面，它都会一直盖在那些页面上——抽屉挂在应用顶层，切页时没人管它。
- **本版修法**：抽屉严格只属于彩签页——离开彩签页它随页隐藏、其他页面绝不出现；开关状态与选中的分类在切页间保持，切回彩签页时原样恢复（与会话列表同口径）。

## 6. 顺查结论：「节点启动」不会在同一进程里跑两遍

针对真机日志里托盘隐藏后又出现一条「节点启动」：已查代码确认——全应用只有一个启动入口、节点只在启动 setup 里创建一次；单实例唤醒（应用已在托盘时再点图标）只把已有窗口显示出来并聚焦，**不会**重跑节点启动、也不会重复启动经典蓝牙服务端，不存在自己抢自己端口的隐患。你日志里第二条「节点启动」只能来自一个新进程（前一进程已退出后重新打开应用），旁证是第二轮启动没有再报端口被占（WSA 10048）——端口已经空出来了。本项无需改代码。
