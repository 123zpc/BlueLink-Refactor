# QA 验收记录（第一册 · 自 v1.0.0 起）

v1.0.0 是 BlueLink 的首个正式版本。本册自 v1.0.0 重新起册，只收录正式版及之后的验收记录；此前测试阶段的验收条目已随旧版本文档一并清理，不再保留。

编号自 166 起（承接项目内部 QA 流水号，便于与历史沟通对齐）。每条记录：在实际运行的应用中逐项操作、截图或日志取证；未验项如实标注，不以代码覆盖冒充实证。

## v1.0.0（首个正式版）

166. **#19 SimpleBLE/BLE 切片重组**：`SliceDecoder` 重写——期望序号锚定 0，乱序片入 pending 表入座等待，窗口 64 占满才判缺片并计 gaps，重复/迟到计 dups，按序交付计 reordered；`decode()` 返回按序帧列。单测覆盖：每 3 片逆序+跨组交换、多文件连发 LCG 洗牌零错位、真丢窗口跳过、序号回绕。transport 19 测试全过。真蓝牙环境复测未做（如实未验，见 186）。
167. **#17 告别信号（Goodbye）**：协议新增 `Control::Goodbye`（type_code 0x32，旧版解不出按坏帧丢弃、混版安全）。发送侧 `disconnect()` 先以 300ms 超时 best-effort 发帧再关连接；接收侧标记 peer_goodbye 并登记 10 分钟重连抑制，本次断开改判「对方主动断开」不触发自动重连；另加冷静期兜底（120 秒窗内连续意外中断计数，首次重连额外等待 (n-1)×5 秒、封顶 30 秒）。rig 双向实证（上轮盲区专补）：案例 1 节点 bye → 应用日志「收到对方主动断开信号（Goodbye）……不触发自动重连」、等 12 秒零重连、落连接页无横幅；案例 2 应用点断开 → 节点（拨号方）日志同款改判、12 秒后连接状态 false、零重连。截图 qa/v100-17-bye-case1.png。
168. **#16 剪贴板三本账**：状态机拆三本账——本机基线（仅本机复制/回读更新）、发送登记表（上限 16、永不被接收事件冲掉）、已应用登记（内容+线上哈希+回读哈希）；等价判定 `clip_equiv`（文字归一化行尾比对；图片同尺寸+alpha 全容忍+其余字节差异 ≤0.1%）；回声判定优先于基线判定；写入路径加计数日志「本进程第 N 次剪贴板写入」。单测 3 个新增。rig 冒烟（Linux/X11，字节一致场景）：A→B 同步成功（节点写入计数=1）、B→A 同步成功、双向零回传零重复发送、监视器自识别「读到的是同步写入的内容，不回发」。格式转换型回声（读回字节≠线上字节）由单测覆盖；Windows 实机面未验（见 186）。
169. **#1 AI 等待/流式气泡锚点**：病根——等待行默认插到「最后一条我方消息」之后且 anchorId 错绑上一问，流式气泡即等待行原地转、共病。修复：`showAiWaiting({bindNext})`，发送时挂末尾不绑旧消息、问题行落库时绑其 id 挪正下方；ai_chunk 兜底建行同规。rig 真上游实证（本地中继注入 DeepSeek 凭据打真接口）：聊天 @AI 与 AI 页各两问连发，第二问等待气泡紧贴第二问正下方、完成态顺序正确（qa/v100-01-ai-anchor-wait.png、qa/v100-01-ai-anchor-done.png）。流式中途态因上游 <2.5s 答完未拍到，在飞锚定由等待态+完成态两端与「同一元素原地转」的代码事实共同证明，如实注记。
170. **#2 前端传输独立记账**：state 新增 transfers 权威账（transfer_id → msgId/进度/终态），气泡迟建时按账回放进度与终态，绘制体与事件/回放共用；删除共享 lastFileBubble。rig 回归（日志原案 3×约 575KB 文本 1 秒内连珠）：中途截图每气泡独立进度、落定全「已送达」、节点落盘三文件 md5 与源逐一相同（qa/v100-02-burst-mid.png、qa/v100-02-burst-done.png）。对已终态传输点取消的路径仅代码覆盖（LAN 太快抓不住在飞态），如实注记。
171. **#3 收藏/置顶不改变气泡尺寸**：定因——meta 行与气泡同列、列宽取两者最大值，「收藏→已收藏」多一字撑宽列。修复：fav/pin 两钮定宽 48px 居中，切换只换字与颜色。rig 量测（PIL 严格白像素）：基线/已收藏/已置顶三态 248×39 全等；最终二进制复验收藏开/关两态 262×39（含量测窗边常数偏移）Δ=0（qa/v100-03-bubble-base/faved/pinned.png、qa/v100-03-recheck-favon/favoff.png）。
